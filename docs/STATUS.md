## 열린 위험

- **복지로 중앙부처 API 개발계정 트래픽 100**: 461건을 모두 상세 조회하면 최소 5일이 걸린다(계산). 한도를 기능별로 세는지는 미확인이다. 응답을 저장해 두고 재사용한다(AGENTS.md).
- **LH 자격조건 대부분은 공고문 첨부파일(PDF·HWP)에 있다**: 상세 API에 서술형이 일부 있을 뿐이다. 첨부파일을 읽지 않으면 LH는 공고 링크와 마감일만 주는 출처가 된다.
- **API 키 공유 방식**: 저장소 밖에서 공유한다. 채팅 AI에 키나 `.env` 내용을 붙여넣지 않는다.
- **일정**: 주차별 계획이 없다. Q5(인원·역할)가 정해지면 세운다.
