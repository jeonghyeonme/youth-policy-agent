## 열린 위험

- **참가격 API 트래픽 하루 2,000**: 가격은 판매점별·상품별로 나눠 불러야 한다. 판매점 수에 따라 한도 안에서 나눠 받고, 받은 응답은 저장해 재사용한다(AGENTS.md).
- **판매점이 대형마트 위주**: 편의점 가격은 거의 없다. 타깃을 정할 때(Q1) 고려한다.
- **`.env.example`이 청년 정책 API 기준일 수 있음**: 확인하지 못했다. T3 전까지 새 팀원이 잘못된 키 이름을 쓸 수 있다.
- **API 키 공유 방식**: 저장소 밖에서 공유한다. 채팅 AI에 키나 `.env` 내용을 붙여넣지 않는다.
- **일정**: 주차별 계획이 없다. Q5(인원·역할)가 정해지면 세운다.
