# D2. 측정용 대표 질문을 A(취업·지원금)와 B(자취·월세)로 정한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-07 PM · 원래 Q2 · PR jeonghyeonme/youth-policy-agent#1

**정할 것**: 사회 초년생이 던질 대표 질문 2~3개 (Q2). API별 컨텍스트 소모량 측정(T4)에서 API를 어떤 조건으로 부를지 정한다.

**검토한 선택지**: [후보 A~D](../../experiments/context-measurement/question-candidates.md)
1. A — "서울 사는 26살인데 아직 취업 못 했어요. 받을 수 있는 지원금 있어요?" (코드 조건)
2. B — "첫 직장 때문에 자취를 시작해요. 연봉 3천인데 월세 지원 받을 수 있나요?" (서술형 조건)
3. C — 중소기업 재직자 목돈 마련 (API 하나로 끝나는 기준값)
4. D — 부산 예비창업자 (A와 조건 종류가 겹침)

**결정**: A와 B 두 개로 측정한다. C·D는 쓰지 않는다.

**이유**: 두 질문을 합치면 후보 API 다섯 개를 모두 한 번 이상 부른다. 또 A는 코드 필터 조건을, B는 서술형 자격 조건을 대표한다. 그래서 두 질문의 측정값 차이가 Q3(핵심 변수)와 Q4(서술형 조건 판단 주체)의 근거가 된다. 질문을 두 개로 줄이면 복지로 중앙부처 한도(100) 안에서 호출 여유도 남는다(계산 없음, 가정).

**다시 볼 때**: 측정에서 A·B로 부르지 못하는 API가 나올 때. 예를 들어 온통청년 개편 API가 취업상태 코드로 거르지 못하면 다시 정한다.
