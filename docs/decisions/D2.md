# D2. LH 공고는 공고명·링크·마감일만 보여 주고, 자격조건은 다루지 않는다

> [결정 기록 인덱스](README.md) · 승인: 2026-10-29 PM · 원래 Q1의 일부 · 근거 자료: [api-survey 확인 결과](../../experiments/api-survey/findings.md) · [log/007](../log/007.md)

**정할 것**: LH 분양·임대 공고의 자격조건을 어떻게 다룰지.

**검토한 선택지**:
1. 공고명, 지역, 상세 링크, 마감일만 보여 준다. 자격조건은 사용자가 공고문에서 직접 확인한다.
2. 상세 API의 첨부 공고문(hwp·pdf)을 받아 자격조건을 뽑는다.
3. LH를 출처에서 뺀다.

**결정**: 1번.

**이유**:
- 임대 공고 상세 5건 중 4건은 공고내용(`PAN_DTL_CTS`)이 비어 있고, 자격조건은 첨부 공고문에만 있다(샘플 실측).
- 2번은 hwp 파싱이 필요하고, 뽑은 긴 공고문을 LLM에 넘기면 무료 LLM 한도를 크게 쓴다. 4~5주 일정에 맞지 않는다.
- 3번보다 1번이 낫다. 온통청년에 없는 실제 모집 공고와 마감일은 사용자에게 쓸모가 있다.

**따라오는 것**:
- LH 상세 API(15057999)는 서비스에서 쓰지 않는다. 수집은 목록 API(15058530)만 하고, 공고유형이 임대주택인 것만 남긴다. 최근 60일 목록 300건 중 임대주택은 73건(24%)이었다.
- LH 공고는 서버 필터(지역, 마감 여부)만 거치고 LLM에는 넘기지 않는다.

**다시 볼 때**:
- 공고내용 필드가 대부분 채워지게 되거나, LH가 자격조건을 구조화된 필드로 줄 때.
- 일정에 여유가 생겨 공고문 파싱을 시도할 때.
