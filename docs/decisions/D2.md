# D2. 컨셉을 청년 정책 안내 에이전트로 확정한다 (D1을 대체한다)

> [결정 기록 인덱스](README.md) · 승인: 2026-11-02 PM · 원래 Q7 · 근거 자료: [3안 점수표](../reference/concept-scorecard.md), [대시보드](https://claude.ai/artifact/W7N3zi26ewZkHrYMN5ZPMf) · [log/014~026](../log/README.md)

**정할 것**: 세 컨셉 중 무엇으로 개발할지 (Q7). D1(생필품 가격)을 유지할지 포함.

**검토한 선택지**:
1. 청년 정책 안내 에이전트 — 온통청년·잡알리오·LH·복지로 데이터, 질문당 LLM 2회
2. 법률 정보 에이전트 — 국가법령정보 API. 무료 LLM 조건에 맞추려면 노동·주거(법령 4개)로 좁혀야 함
3. 생필품 가격 에이전트 (D1) — 참가격 API

**결정**: 1번. 청년 정책 안내 에이전트로 개발한다. D1을 대체한다.

**이유**:
- 같은 조건(Groq gpt-oss-120b, 질문당 LLM 2회)으로 두 안을 질문부터 답까지 실측했다. 질문당 토큰은 청년 3,540, 법률 약 3,100으로 비슷하다(실측). 쓸모 있는 근거 비율은 법률 11/12, 청년 17/21로 법률이 조금 높다(실측, AI 판단). 두 안의 질문은 모두 AI가 준비했다.
- 같은 비용으로 다루는 범위가 청년 정책이 넓다: 분야 5개·정책 4,598건 대 노동·주거·법령 4개(실측). 법률 정보의 범위는 니즈가 아니라 무료 LLM 제약 때문에 좁힌 것이고, 노동 분야는 고용노동부 AI 노동법 상담이 이미 답한다(확인).
- 틀렸을 때 피해가 작다. 청년 정책은 신청 단계에서 기관이 자격을 다시 확인하고, 법률 정보는 바로잡는 단계가 없다(판단).
- 처음 기준이 "니즈 충족"이었다. 점수표 합계는 법률 3.52, 청년 3.42로 법률이 조금 높지만 그 차이는 만드는 쪽 장점(API 하나, LLM 역할)에서 나오고, 사용자 쪽 소계는 청년 2.52가 가장 높다(점수표, 추정 포함).
- 생필품 가격은 어떤 가중치에서도 3위였다. 핵심 기능(최저가 매장, 장바구니 비교)이 참가격에 이미 있다(확인).

**감수할 것**: 공공 API 5개의 수집·갱신 부담, 2회차 형식 오류(실측 2/10) 재시도, 자격 정보가 비어 있을 때 "제한 없음"으로 읽지 않는 규칙, 온통청년 AI 챗봇과의 차별점(여러 출처 묶기, 서술형 자격 풀이)을 첫 화면에서 보여 주기.

**다음**: `main`을 청년 정책 기준으로 되돌린다. 청년 정책 작업은 `claude/exciting-goldberg-y71yhi`(기반 `archive/youth-policy`)에 있다. 그 브랜치의 결정 번호 D1~D3(데이터 미리 수집, LH 링크만, LLM 질문당 2회)는 `main`의 D1·D2와 번호가 겹치므로 합칠 때 번호를 다시 매긴다.

**다시 볼 때**: 정책 선택 품질이 실제 사용자 질문에서 크게 떨어질 때, 공공 API 수집·갱신이 일정 안에 끝나지 않을 때, 유료 LLM이 허용돼 법률 정보의 범위 제약이 풀릴 때.
