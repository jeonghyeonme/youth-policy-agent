# D12. 서비스 코드는 저장소 루트의 `web/`에 둔다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-08 PM · 원래 Q7

**정할 것**: Next.js 프로젝트(D11)를 둘 디렉토리. 최상위 디렉토리 추가라 PM 승인 대상(AGENTS.md "구조").

**검토한 선택지**:
1. 루트에 `web/`
2. 저장소 루트에 바로

**결정**: 1. `web/`. Vercel 프로젝트의 Root Directory를 `web`으로 둔다.

**이유**: `docs/`, `experiments/`와 나란히 두어 Next.js 설정 파일(`package.json`, `next.config` 등)이 문서와 섞이지 않는다. Vercel은 기준 폴더만 한 번 지정하면 된다.

**다시 볼 때**: 서버를 따로 떼어야 할 만큼 커질 때.
