# 결정 기록 — 인덱스

> 결정 하나에 파일 하나(`D<번호>.md`)로 남긴다. 결정은 고치지 않는다 — 바뀌면 새 번호를 만들고 "D<n>을 대체한다"고 적는다.
> 여기에는 **PM이 승인한 결정**만 들어온다. 승인 전에는 [STATUS](../STATUS.md) "PM 승인 대기"(Q 번호)에 있다.
> 작업 안에서 작업자가 정해도 되는 작은 결정은 여기가 아니라 그 작업의 `log/NNN.md` "근거"에 적는다. 무엇이 PM 승인 대상인지는 [AGENTS.md](../../AGENTS.md#pm-승인이-필요한-결정)에 있다.

## 새 결정 쓰는 법

1. 다음 번호로 `D<번호>.md`를 만든다.
2. 아래 틀을 채운다.
3. 위 요약표에 한 줄 추가하고, STATUS "PM 승인 대기"에서 해당 Q를 지운다.

```markdown
# D<번호>. <결정 — 한 문장>

> [결정 기록 인덱스](README.md) · 승인: YYYY-MM-DD PM · 원래 Q 번호 · 이슈/PR #n

**정할 것**: (원래 Q 번호가 있으면 함께)
**검토한 선택지**:
1. …
2. …
**결정**: …
**이유**: 수치가 있으면 출처(실측/계산/가정)를 표시한다
**다시 볼 때**: 이 결정을 바꿔야 하는 조건
```
