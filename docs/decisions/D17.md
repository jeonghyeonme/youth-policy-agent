# D17. 저장소가 공개됐으므로 GitHub Actions CI 자동 실행을 다시 켠다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-16 PM · 원래 Q 번호 없음 · [D15](D15.md)를 대체한다(D3·D4의 CI 조건으로 돌아간다)

**정할 것**: D15의 "다시 볼 때"(저장소 공개)가 됐다. 2026-11-16 확인: GitHub API에서 `visibility: public`.

**결정**: CI 자동 실행을 다시 켠다. 트리거는 모든 PR과 `main` 푸시다(D16으로 기준 브랜치가 `main`이 됨). PR은 CI가 통과해야 병합한다(D3·D4).
- `.github/scripts/check_all.py`는 남긴다. PR을 올리기 전에 로컬에서 같은 검사를 돌릴 때 쓴다.

**이유**: 공개 저장소의 GitHub 호스팅 러너는 무료다. 깨끗한 환경에서 검사하는 보장(D15에서 잃었던 것)을 되찾는다.

**다시 볼 때**: 공개 저장소에서도 실행 서버가 배정되지 않을 때(계정 결제 잠금이 공개 저장소에도 걸리는지는 확인하지 않았다).
