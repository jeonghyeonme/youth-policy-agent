# D7. LLM 모델은 Groq의 openai/gpt-oss-120b로 진행한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-08 PM · 원래 Q5의 일부(모델)

**정할 것**: Groq에서 쓸 모델 (D5에서 업체만 정하고 남긴 것)

**검토한 선택지**: [Groq 모델 조사](../../experiments/context-measurement/groq-models.md)
1. `openai/gpt-oss-120b` (Production)
2. `openai/gpt-oss-20b` (Production, 120b와 한도 같음, 더 빠름)
3. `qwen/qwen3.8-27b` (Preview)
4. `llama-3.3-70b-versatile` (문서끼리 상태가 다름, 무료 플랜 종료일 2026-08-16 공지)

**결정**: 1. `openai/gpt-oss-120b`.

**이유**: Production이고 지원 중단 공지가 없다. 도구 호출을 지원한다. 토크나이저(o200k)가 공개돼 있어 서버에서 넘길 건수를 토큰으로 미리 계산할 수 있다. 측정에서도 이 토크나이저로 셌다(온통청년 정책 1건 약 280토큰).

**아직 모르는 것**: 계정의 무료 한도. 문서에 분당 8,000토큰과 250,000토큰이 함께 나와 콘솔(Settings → Limits)에서 확인해야 한다.

**다시 볼 때**:
- 한국어 답변 품질이 모자라거나 응답이 느릴 때: 같은 한도의 `openai/gpt-oss-20b`와 비교한다.
- 무료 한도 때문에 시연이 막힐 때: 넘길 건수를 줄이거나 D5(업체)를 다시 본다.
