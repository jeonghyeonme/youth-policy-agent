# D13. Next.js가 만드는 `web/AGENTS.md`를 커밋한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-13 PM · 원래 Q8

**정할 것**: `create-next-app`과 `next dev`가 만드는 AI 도구 안내 파일 `web/AGENTS.md`를 저장소에 둘지. AI 도구 규칙 파일 추가라 PM 승인 대상(AGENTS.md "규칙").

**검토한 선택지**:
1. 커밋한다
2. `.gitignore`로 뺀다

**결정**: 1. 커밋한다. 내용은 Next.js가 관리하는 블록 그대로 두고 손대지 않는다.

**이유**: 내용은 "이 Next.js 버전은 바뀐 점이 많으니 `node_modules/next/dist/docs/`의 문서를 먼저 읽으라"는 안내다. 무해하고, AI 도구가 Next 16의 바뀐 API를 틀리지 않게 돕는다. 빼 두면 `next dev`를 돌릴 때마다 다시 생겨 작업 트리가 지저분해진다.

**지킬 것**: 저장소 루트 `AGENTS.md`의 규칙(키, 개인정보, 트래픽, PM 승인)이 우선이다. `web/AGENTS.md`에 이 저장소의 규칙을 따로 적지 않는다(같은 내용을 두 곳에 두지 않는다).

**다시 볼 때**: Next.js가 이 파일에 저장소 규칙과 부딪히는 지시를 넣을 때.
