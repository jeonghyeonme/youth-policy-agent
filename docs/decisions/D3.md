# D3. GitHub Actions로 CI를 돌린다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-07 PM · 원래 Q 번호 없음(PM 직접 지시) · PR jeonghyeonme/youth-policy-agent#1

**정할 것**: 푸시·PR마다 자동 검사를 돌릴지, 돌린다면 어디서 무엇을 돌릴지

**검토한 선택지**:
1. CI 없이 리뷰어가 손으로 확인한다
2. GitHub Actions로 측정 스크립트 테스트와 문서 링크 검사를 돌린다

**결정**: 2. `.github/workflows/ci.yml`이 모든 PR과 `archive/youth-policy` 푸시에서 두 가지를 돌린다.
- `experiments/context-measurement/test_measure.py`
- `.github/scripts/check_links.py`: Markdown 상대 링크가 실제 파일을 가리키는지 확인

공공 API는 호출하지 않고, 키도 쓰지 않는다(AGENTS.md "트래픽", "API 키"). 그래서 저장소 Secrets도 쓰지 않는다.

**이유**: 지금 산출물은 대부분 문서다. 문서끼리 링크로 이어져 있어서(STATUS → D·log·실험), 파일을 옮기거나 지우면 링크가 깨지기 쉽다. 측정 스크립트는 T4에서 실제 샘플로 고치게 되므로 회귀 검사가 필요하다.

**비용**: 비공개 저장소는 GitHub Free 기준 Actions가 월 2,000분 무료다. 한 번에 1분 안쪽으로 끝나는 작업이라 한도에 닿을 일은 거의 없다(가정, 실측 아님). 저장소를 공개하면(T5) 무료다.

**다시 볼 때**: 기술 스택(Q6)이 정해져 코드 디렉토리가 생길 때. 그 언어의 린트·테스트를 이 워크플로에 더한다.
