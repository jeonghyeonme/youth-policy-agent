# D11. 기술 스택은 Next.js(TypeScript), 호스팅은 Vercel 무료로 한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-08 PM · 원래 Q6

**정할 것**: 기술 스택과 호스팅 (Q6)

**검토한 선택지**: [Q6 추천안](../reference/q6-tech-stack.md)
1. Next.js(TypeScript) 한 저장소 + Vercel
2. FastAPI(Python) 서버 + React(Vite) 화면
3. Streamlit(Python)

**결정**: 1. Next.js(TypeScript). 화면과 서버(API Route)를 한 프로젝트에 두고 Vercel 무료(Hobby) 플랜에 배포한다.

**이유**:
- 배포가 한 곳이라 4~5주 일정에 유리하다.
- 대화는 브라우저 `sessionStorage`, 키와 공공 API·Groq 호출은 API Route에 둔다. 제안서·AGENTS.md의 개인정보·키 원칙과 맞다.
- 선택지 버튼, 판정 카드(D10), 스트리밍 답변을 자유롭게 만든다.
- 실험의 Python 필터·순위·판정 로직(D9, D10)은 순수 함수라 TypeScript로 옮기는 비용이 작다.

**지킬 것**:
- 서버 코드는 요청 본문(대화·선택값)을 로그에 찍지 않는다. Vercel 요청 로그에도 남지 않게 한다(AGENTS.md "개인정보").
- 키는 Vercel 환경변수에만 둔다. 이름은 `.env.example`과 같게 한다.
- 공공 API 응답 캐시는 서버 메모리, 짧은 만료(D8).

**아직 안 정한 것**: 코드를 둘 디렉토리(Q7, 최상위 디렉토리라 PM 승인 대상).

**다시 볼 때**: 팀원이 TypeScript를 다루기 어려워 일정이 밀릴 때(Q5). Vercel 무료 플랜 제한(함수 실행 시간 등)에 걸릴 때.
