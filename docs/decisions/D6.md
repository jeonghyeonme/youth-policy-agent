# D6. 온통청년과 함께 묶을 API는 LH 하나로 시작한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-08 PM · 원래 Q1

**정할 것**: 온통청년과 함께 쓸 공공 API (Q1)

**검토한 선택지**: [측정 결과의 Q1 추천안](../../experiments/context-measurement/results.md#q1-추천안-온통청년--lh로-시작한다)
1. 온통청년만
2. 온통청년 + LH 분양·임대 공고
3. + 복지로 중앙부처
4. + 복지로 지자체
5. + 잡알리오 공공기관 채용

**결정**: 2. 온통청년 + LH로 진행한다. 복지로 두 API와 잡알리오는 지금 쓰지 않는다.

**이유**:
- LH는 주거 질문(대표 질문 B)에 지금 모집 중인 임대 공고와 신청 링크를 더한다. 온통청년에는 없는 정보다.
- LH는 비용이 가장 작다. 건당 약 650자, 질문당 1회 호출, 개발계정 한도 10,000(실측·제안서).
- 복지로는 온통청년과 비슷한 정책이 많고(이름 비교로 141건 중 20건, 대략값), 중앙부처는 한도 100에 상세가 커서 비싸다.
- 잡알리오는 정책이 아니라 채용 공고라서 범위가 넓어진다. 건당 크기도 가장 크다.

**다시 볼 때**:
- 온통청년이 요청 단계에서 지역으로 거르지 못해 대표 질문 A 같은 경우에 결과가 안 나올 때: 지역으로 거를 수 있는 복지로 지자체를 다시 본다.
- 정책 안내가 동작한 뒤 범위를 넓힐 때: 잡알리오를 다시 본다.
