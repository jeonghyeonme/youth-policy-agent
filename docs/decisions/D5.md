# D5. LLM 업체는 Groq로 진행한다

> [결정 기록 인덱스](README.md) · 승인: 2026-11-08 PM · 원래 Q5의 일부(LLM 업체)

**정할 것**: 무료 LLM API를 어느 업체로 쓸지 (Q5 중 업체 부분)

**검토한 선택지**: 별도 비교 문서 없이 PM이 정했다. PM이 Groq 키를 이미 발급받아 로컬 `.env`에 `GROQ_API_KEY`로 넣어 두었다.

**결정**: Groq로 "일단" 진행한다. `.env.example`의 `LLM_API_KEY`를 `GROQ_API_KEY`로 바꾼다.

**아직 안 정한 것**: 모델(토큰 계산 기준이 모델에 따라 다르다), 팀 인원·역할(Q5의 나머지).

**이유**: PM 판단. 키가 이미 있어 바로 쓸 수 있다.

**다시 볼 때**: 모델을 고를 때 무료 한도(분당·일당 토큰)가 측정 결과([results.md](../../experiments/context-measurement/results.md))의 컨텍스트 크기를 감당하지 못하면.
