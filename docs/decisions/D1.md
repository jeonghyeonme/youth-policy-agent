# D1. 컨셉을 청년 정책 안내 에이전트에서 생필품 가격 에이전트로 바꾼다

> [결정 기록 인덱스](README.md) · 승인: 2026-10-30 PM · 원래 Q 번호 없음

**정할 것**: 프로젝트 컨셉과 활용 공공 API를 바꿀지

**검토한 선택지**:
1. 청년 정책 안내 에이전트 유지 — 온통청년 청년정책 API 중심, 대상 사용자는 사회 초년생
2. 생필품 가격 에이전트로 변경 — 한국소비자원 참가격 생필품 가격 정보 API(공공데이터포털 15158701)

**결정**: 2. `main`은 생필품 가격 에이전트로 간다. 청년 정책 작업은 `archive/youth-policy` 브랜치에 남기고, 청년 정책 관련 작업 브랜치는 그 브랜치를 대상으로 PR한다.

바뀌는 것은 활용 API와 컨셉(대상 사용자, 서비스 내용)뿐이다. 목표(포트폴리오·학습), 기술 제약(LLM 기반, 무료 LLM API, 팀 작업, 4~5주), 서비스 흐름(채팅 → 선택지로 조건 받기 → API 호출 → 서버 필터링 → LLM 답변), 개인정보 원칙, 키 관리 방식은 그대로다.

타깃 사용자와 구체 기능은 참가격 API를 호출해 데이터를 분석한 뒤 정한다(STATUS Q1).

**이유**: 청년 정책 쪽이 아쉬웠던 것은 아니지만, 생필품 가격 쪽이 니즈가 더 좁고 날카로워 니즈 충족에 더 현실적으로 다가간다(PM 판단, 수치 근거 없음).

**다시 볼 때**: 데이터 분석(STATUS T4)에서 어떤 타깃에도 쓸 만한 기능을 만들 수 없다고 나오면.
