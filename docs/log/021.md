# 021. 정해진 결정들을 요구로 모아 Q6 기술 스택 추천안을 올렸다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: Q6, Q5, D6~D10

**계기**: PM이 Q6(기술 스택) 추천안을 요청했다.

**한 일**: `docs/reference/q6-tech-stack.md`에 요구(제안서·D6~D10), 선택지 3개 비교, 추천(Next.js + Vercel), 함께 정할 것(호스팅, 코드 디렉토리)을 썼다. STATUS Q6 줄에 연결했다. 결정은 PM이 한다.

**근거**:
- 추천은 팀 언어 경험(Q5)을 모르는 상태에서 했다. 그래서 "팀이 Python 위주면 FastAPI + React"를 조건으로 달았다.
- Streamlit은 대화 상태를 서버 세션에 두는 구조라 제안서의 "대화는 브라우저에만" 원칙과 맞지 않아 제외를 권했다.
- 문서 위치: 실험이 아니라서 `experiments/`가 아닌 `docs/reference/`에 뒀다.

**확인**: 문서만 바뀌었다. 링크 검사 통과. 호스팅 플랜의 구체 제한 수치는 확인하지 않았다(문서에 적음).
