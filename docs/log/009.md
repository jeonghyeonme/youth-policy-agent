# 009. 무료 LLM API를 비교하고 Groq를 주 업체로 추천했다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q5, D3

**계기**: D3(질문당 LLM 최대 2회)이 정해져 업체 선택 기준이 생겼다. PM이 Q5 비교표를 요청했다.

**한 일**:
- [llm-providers/comparison.md](../../experiments/llm-providers/comparison.md)에 무료 LLM API 8곳의 한도, 입력 데이터 사용, 판단을 정리했다.
- STATUS Q5에 추천안(주 업체 Groq, 예비 Mistral)을 적었다.

**근거**:
- D3의 1회차 호출에는 사용자 문장이 그대로 간다. 그래서 한도만큼 입력 데이터 사용 조건을 무겁게 봤다.
- Gemini 무료 약관은 입력을 제품 개선에 쓰고 사람이 읽을 수 있으며, 개인 정보를 보내지 말라고 적고 있다(공식 약관).
- Groq는 추론 데이터를 기본으로 보관하지 않고 무보관 설정이 있다(공식 문서). Groq의 실제 상한은 하루 200K 토큰이다. 질문 하나에 3K~6K 토큰이라고 가정하면 하루 33~66개다. 토큰은 가정이고 W6에서 잰다.
- 제3자 비교 사이트의 숫자는 서로 달랐다. 공식 문서로 확인한 것과 제3자가 전한 것을 표에 구분해 적었다.

**확인**: 공식 문서 7곳(Gemini 한도·약관, Groq 한도·데이터, OpenRouter 한도, Mistral 도움말 2건)을 읽었다. 한국어 품질과 JSON 출력은 시험하지 않았다.
