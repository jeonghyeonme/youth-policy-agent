# 009. 측정 결과로 Q1 추천안(온통청년 + LH)을 올렸다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: Q1, T4

**계기**: PM이 Q1(온통청년과 묶을 API) 추천안을 요청했다.

**한 일**: `results.md`에 선택지 5개 비교표와 추천안을 쓰고 STATUS Q1 줄에 연결했다. 결정은 PM이 한다.

**근거**:
- 크기·호출·한도: `results.md`의 실측값.
- 겹침: 샘플에 있는 복지로 141건(중앙·지자체 목록)과 온통청년 200건의 이름을 공백·괄호·숫자·"청년"을 지우고 서로 포함되는지로 비교했다. 20건이 비슷했다. 다른 지자체의 같은 종류 정책도 비슷하다고 잡히므로 실제 겹침보다 많게 나올 수 있다.

**확인**: 링크 검사 통과. 겹침 비교는 대략적인 이름 비교이고, 같은 정책인지 하나씩 확인하지 않음.
