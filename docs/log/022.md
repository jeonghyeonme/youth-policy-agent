# 022. 청년 정책 실측을 점수표와 대시보드에 반영했다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: PM이 청년 정책 질문→답 실측(log/021)을 점수표와 대시보드에 반영해 달라고 했다.

**한 일**:
- [concept-scorecard.md](../reference/concept-scorecard.md) 6절: 두 안 실측 비교표, 청년 정책 3·4·7번 근거를 실측으로 바꿈.
- [대시보드](https://claude.ai/artifact/W7N3zi26ewZkHrYMN5ZPMf): "질문→답 실측" 절(두 안 카드), 질문당 토큰 차트에 청년 y1 추가, 점수판 근거 문장 갱신, 결론 문장에 실측 언급.

**근거**: 실측이 5절의 추정(커버리지 4, 정확성 3.5)과 맞아 점수는 바꾸지 않았다. 합계는 법률 3.52, 청년 3.42 그대로이고, 사용자 쪽 소계는 청년 2.52가 가장 높다.

**확인**: 대시보드 스크립트 문법 검사만 했다. 렌더링과 자체 검사 결과는 확인하지 않았다.
