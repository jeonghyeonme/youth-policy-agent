# 015. 순위 기준 6가지를 샘플에 돌려 Q3 추천안(3단계 고르기)을 올렸다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: Q3, D7, D8

**계기**: PM이 Q3 추천안을 요청했다. 측정에서 걸러도 정책이 약 160건 남고(log/011), 한 번에 15건 안팎만 넘길 수 있다(log/012).

**한 일**:
- `rank_experiment.py`: 저장된 온통청년 샘플에 순위 기준 6가지(API 순서, 조회수, 마감 임박, 지역 전용, 키워드 일치, 조합)를 돌려 상위 10건을 비교한다. 날짜는 샘플 받은 날(2026-11-08)로 고정했다.
- `q3-ranking.md`에 결과와 추천안(요청 좁히기 → 서버 필터 → 순위 상위 8건)을 쓰고 STATUS Q3에 연결했다. 결정은 PM이 한다.
- `fetch_samples.py`에 확인용 호출 2회(정책 키워드 `plcyKywdNm=보조금`, 중분류 `mclsfNm=취업`)를 넣었다. 아직 실행하지 않았다.

**근거**:
- 질문에서 뽑을 키워드는 LLM이 한다고 가정하고 사람이 정했다(A: 지원금·보조금·수당·장기미취업, B: 월세·임차·주거비).
- 평가는 정답 목록 없이 두 지표로 했다: 상위 10건의 키워드 일치 수, B에서 "청년 월세 지원"의 순위.
- 8건은 분당 8,000토큰 가정에서 정책 외 부분에 5,000토큰을 남기는 값이다.

**확인**:
- 실험은 샘플로 실제로 돌렸다(실측). A는 첫 100건만 봤고, 종로구 전용 정책이 없어 "지역 전용 우선"은 제대로 시험되지 않았다.
- 정책 키워드·중분류로 API가 좁혀지는지는 확인하지 않음(호출 2회 대기 중).
