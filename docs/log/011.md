# 011. 온통청년은 시군구 코드로 거를 수 있지만 걸러도 크다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: T4, D6, Q3

**계기**: 대표 질문 A가 0건이 나와(log/007), 온통청년이 요청 단계에서 지역으로 거르는지 확인해야 했다. D6의 "다시 볼 때" 조건이다.

**한 일**:
- 공개 문서 확인: 공공데이터포털 소개(15143273)에 "법정시군구코드를 파라미터로 받는다"는 문장만 있고 파라미터 이름은 없었다. 온통청년 문서 표는 JS로 그려져 읽지 못했다.
- `fetch_samples.py`에 확인용 호출 3개(`zipCd` 5자리·앞자리·두 개)를 넣고, PM이 로컬에서 실행해 push했다.
- `results.md`에 결과와 A 재계산, `api-survey.md`에 필터 사용법, STATUS의 위험·Q3 갱신.

**근거**:
- 응답 필드 이름(`lclsfNm`)이 요청 파라미터로도 동작했으므로 `zipCd`도 같을 것으로 보고 이 이름으로 시험했다.
- 필터가 동작했는지는 전체 건수(`totCount`)가 1,503에서 줄어드는지와, 받은 결과가 모두 그 코드를 포함하는지로 판단했다.

**확인**:
- 실측: 종로구 5자리 → 297건, 100건 모두 코드 포함. 앞자리 `11` → 1,503건(필터 없는 응답과 바이트까지 같음).
- 두 코드를 넣은 결과는 종로구 하나와 같았다. 두 번째 코드가 무시되는지는 구분하지 못했다.
- A 재계산(약 160건, 약 8만 자)은 받은 100건의 통과 비율(53%)을 전체 297건에 곱한 추정이다.
