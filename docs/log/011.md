# 011. 무료 LLM 후보 시험 스크립트를 만들었다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: T9, Q5, D3

**계기**: Groq 키 확인이 통과했다. Q5를 정하기 전에 한국어 품질, JSON 출력, 질문당 토큰을 실제로 재야 한다(comparison.md "정하기 전에 시험할 것").

**한 일**:
- `experiments/llm-providers/trial.py`를 만들었다. D3의 두 호출(해석, 설명)을 모델마다 13회 부르고, 결과를 `results/`에 저장한 뒤 요약을 출력한다.
- 실행 방법을 `experiments/llm-providers/README.md`에 적고, STATUS에 T9를 추가했다.

**근거**:
- Groq 공식 문서상 세 후보 모델 모두 엄격한 JSON 스키마 출력(`json_schema`, `strict: true`)을 지원한다. 그래서 해석 호출의 출력 형식은 스키마로 고정하고, 내용(분야, 나이, 지역, 취업상태, 학력)을 정답과 비교한다.
- 추론 정도는 gpt-oss는 `low`, qwen은 `none`으로 했다. 추론 토큰도 하루 토큰 한도에서 빠지기 때문이다(작업 안에서 정함).
- 설명 시험에 쓰는 정책은 수집한 공개 정책 중 생애주기에 청년이 있고 서술형 자격조건이 있는 것을, 사용자 유형마다 다르게 3건씩 골랐다. 장애인·청소년 대상 정책이 섞여 있어, 해당 안 되는 사람에게 해당 안 된다고 말하는지도 볼 수 있다.
- 질문 10개와 정답은 직접 만들었다. 실제 사용자 문장은 쓰지 않는다.

**확인**: 가짜 응답으로 돌렸다. Groq 세 모델 39회 호출 흐름, 결과 저장, 다시 실행 시 추가 호출 0회, 채점과 요약 출력(질문당 토큰, 하루 처리 가능 질문 수)을 확인했다. Mistral 키가 없을 때 건너뛰는 것도 확인했다. 실제 키로는 돌리지 않았다.
