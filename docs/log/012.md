# 012. Groq 모델을 조사하고 토큰으로 환산해 Q5 모델 추천안을 올렸다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: Q5, Q3, D5

**계기**: PM이 Groq 모델 조사(Q5)를 요청했다.

**한 일**:
- Groq 문서(models, rate-limits, tool-use, deprecations)를 읽고 `groq-models.md`에 모델 비교, 한도, 토큰 예산, 추천안(`openai/gpt-oss-120b`)을 썼다. STATUS Q5에 연결했다. 결정은 PM이 한다.
- `measure.py --tokens`: o200k 토크나이저로 토큰 수를 센다. tiktoken은 선택 설치이고, 옵션을 줄 때만 불러온다. CI·테스트는 tiktoken 없이 돈다(가짜 카운터로 테스트 1개 추가).

**근거**:
- 토크나이저로 o200k를 골랐다. 추천 모델(gpt-oss) 계열이고 공개돼 있다. tiktoken 추가는 실험 폴더 안 선택 기능이라 작업자 판단으로 정했다.
- 한도 계산은 문서의 두 값 중 더 빡빡한 분당 8,000토큰을 썼다. 정책 외 부분 3,000토큰은 가정이다.

**확인**:
- 토큰 수는 샘플로 실측했다(온통청년 200건 55,210토큰, 건당 약 280).
- 단위 테스트 15개 통과, 링크 검사 통과.
- 무료 플랜 한도는 문서로 확정하지 못했다. 문서끼리 다르다(분당 8,000 / 250,000토큰). Llama 두 모델도 페이지끼리 상태가 다르다. 콘솔에서 사람이 확인해야 한다.
