# 012. fallback을 20b로 돌려 1회차가 절반 아래로 준 것을 봤지만, 20b는 형식·내용 오류가 많아 쓰지 않기로 했다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 실행, 커밋 6352f2e) · 관련: Q7, T6

**계기**: 120b가 Groq 하루 한도에 걸려, PM이 `--topics --toc fallback`을 `gpt-oss-20b`로 돌려 푸시했다.

**한 일**: 12건의 오류 응답, 고른 주제, 답을 읽고 답을 `laws/` 원문과 대조했다. README 실행 기록과 STATUS T6을 고쳤다.

**근거**:
- 1회차 토큰(실측): 주제를 고른 질문 2,131~2,380. v5 목차 전체(120b) 약 5,000의 절반 아래다. 1회차는 입력이 대부분이라 120b에서도 비슷하게 줄 것으로 본다(추정, 토크나이저가 같은 계열이라는 가정).
- 20b를 쓰지 않는 이유(실측): 1회차 형식 오류 3/12(120b는 v4·v5에서 0/19). 답을 낸 9건 중 4건에 내용 오류(없는 절차, 틀린 항 번호, 우선변제 요건 누락, 넘겨받은 상한 미언급).
- 인용 검사의 한계를 하나 더 확인했다. 조문 번호만 보고 항 번호(제4조 제4항)는 보지 않는다.

**확인**: 결과에 OC 값 없음. 120b fallback은 아직 돌리지 않았다.
