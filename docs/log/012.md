# 012. LLM 시험 v1을 읽고 v2 프롬프트를 만들고, 온통청년을 공통 형식에 매핑했다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 실행) · 관련: T8, T9, Q5, Q10

**계기**: PM이 LLM 시험 결과(커밋 e117ebe)와 온통청년 샘플(커밋 e67634b)을 푸시했다.

**한 일**:
- 설명 원문 9건을 모두 읽고, 결과를 [comparison.md "시험 결과 v1"](../../experiments/llm-providers/comparison.md)에 정리했다.
- `trial.py`에 v2 프롬프트를 만들었다. 결과는 `results/<버전>/`에 따로 저장하고, v1 결과는 `results/v1/`로 옮겼다. 요약에 설명 속 한자·라틴 문자 낱말 검사를 넣었다.
- `normalize.py`에 온통청년 매핑을 넣고, 공통 분류 이름을 온통청년 새 이름으로 바꿨다. [schema.md](../../experiments/api-survey/schema.md)를 다섯 출처 기준으로 고쳤다.
- STATUS: T7(샘플 수집)을 끝냈다. T8, T9 상태와 Q10 추천안을 고쳤다.

**근거**:
- v1 설명에서 모델마다 다른 실패가 나왔다. gpt-oss-120b는 없는 정보를 가정했고(9건 중 3건), qwen은 외국 문자가 섞였다(3회 중 2회). 둘 다 프롬프트 규칙으로 줄일 수 있는지 v2에서 본다.
- 공통 분류를 새 이름(교육·직업훈련, 금융·복지·문화, 참여·기반)으로 바꾼 이유는 두 가지다. 온통청년이 옛 이름과 새 이름을 섞어 보낸다. 그리고 새 이름에 "금융"이 들어 있어 v1에서 틀린 "목돈 모으기" 같은 질문을 LLM이 맞히기 쉽다. 작업 안에서 정했고, Q10 확정 때 PM이 함께 본다.
- 온통청년 나이는 `sprtTrgtAgeLmtYn` 표시가 값과 어긋나서(`Y`인데 19~39세 317건 등) 최소·최대 나이만 쓴다.
- 지역코드 앞자리 12를 전남광주통합특별시로 본 것은 추정이다. 샘플에 29(광주)와 46(전남)이 없다.

**확인**:
- 온통청년 샘플 37페이지 모두 HTTP 200, 정책 3,664건이 중복 없이 응답의 `totCount`와 같았다. 추정했던 필드 이름(`plcyNo`, `totCount`, `sprtTrgtMinAge` 등)은 모두 맞았다.
- `normalize.py`로 다섯 출처 4,598건을 변환했다. `title`, `url`이 빠진 레코드는 없었다.
- v1 결과를 새 위치에서 다시 집계해 숫자가 PM 출력과 같았고, 외국 문자 검사가 qwen의 세 낱말을 찾았다.
- v2는 가짜 응답으로 39회 흐름과 저장 위치만 확인했다. 실제 키로는 돌리지 않았다.
- 온통청년 상세 페이지 주소가 HTTP 200인 것은 확인했지만, 화면에 정책 내용이 나오는지는 브라우저로 확인하지 않았다.
