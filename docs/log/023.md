# 023. 생필품 가격 실측 1단계(데이터 조사) 스크립트를 만들었다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7, T2·T4(main)

**계기**: PM이 생필품 가격도 실측할 게 있으면 하자고 했다. 3안 중 시험이 하나도 없는 안이다.

**한 일**: [experiments/grocery-e2e/collect.py](../../experiments/grocery-e2e/README.md). 판매점·상품·기준정보 전체와, 품목 12개(우유·라면·세제·커피믹스·종이컵·화장지·생수·식용유·계란·즉석밥·햇반·삼겹살)의 상품 최대 2개씩에 대해 최신 조사일 가격을 받는다.

**근거**:
- 응답 필드 이름이 공공데이터포털 문서에 없어서, 질문→답 스크립트는 실제 응답을 본 뒤 만든다(두 단계).
- 엔드포인트 `https://apis.data.go.kr/B551919/ProductPriceInfoService`(문서 확인). 가격 오퍼레이션 이름은 README의 `getProductPriceInfoSvc`와 `.do` 붙인 이름을 모두 시도한다. 가격 조회만 키 변수가 소문자 `serviceKey`다(문서).
- 호출 약 30회로 하루 한도 2,000의 2% 이내. 응답은 cache에 두고 다시 부르지 않는다(AGENTS.md 트래픽).

**확인**: XML 파싱을 정상 응답 예시와 공공데이터포털 오류 응답 예시로 확인했다. 실제 API는 부르지 않았다.

**추가 (같은 날)**: PM 첫 실행은 API 3회 호출에 판매점·상품 0건이었다. 이 서비스 활용신청을 하지 않은 키였다. 스크립트가 실패를 알리지 않고 0건 요약을 써서, 판매점·상품이 모두 0건이면 요약을 쓰지 않고 이유와 응답 앞부분을 보여 주게 고쳤다. 0건 `survey.json`은 지웠다.
