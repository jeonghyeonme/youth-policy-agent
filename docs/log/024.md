# 024. 대시보드를 청년 정책 대 법률 정보의 핵심 비교만 남기고 줄였다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: PM이 점수표에서 핵심 비교만 시각화하고 나머지와 생필품 가격은 빼자고 했다.

**한 일**: [대시보드](https://claude.ai/artifact/W7N3zi26ewZkHrYMN5ZPMf)를 세 부분으로 줄였다. 결론 문장(두 안 합계, 갈리는 사용자 쪽 비중), 기준별 점수판(두 안, 사용자 쪽·만드는 쪽 소계와 합계), 질문→답 실측 카드. 합계 막대, 오류 방지 작업, 토큰 차트, 예상 질문, 기존 서비스, 의논할 것 절을 뺐다. 쓰지 않게 된 데이터(예상 질문, 기존 서비스, 오류 방지 작업, 토큰)와 옛 점수 파일을 지웠다. 제목을 "청년 정책 대 법률 정보"로 바꿨다.

**근거**: 생필품 가격은 어떤 비중에서도 3위라 결정에 영향이 없다. 점수 데이터에는 생필품 행이 남아 있지만 페이지는 두 안만 그린다. 근거 문서는 저장소 [concept-scorecard.md](../reference/concept-scorecard.md)에 그대로 있다.

**확인**: 페이지 스크립트 문법 검사만 했다.
