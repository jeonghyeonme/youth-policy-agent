# 002. main을 생필품 가격 에이전트 컨셉으로 정리했다 (2026-10-30)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: D1

**계기**: PM이 컨셉을 생필품 가격 에이전트로 바꾸기로 했다(D1). 청년 정책 내용은 `archive/youth-policy` 브랜치(`6857b49`)에 이미 보존돼 있어, `main`만 새 컨셉으로 정리했다.

**한 일**:
- `README.md`: 소개, 왜 만드나, 서비스 흐름, 개인정보 원칙, 공공 API(참가격 오퍼레이션 4개)를 새 컨셉으로 바꿨다.
- `AGENTS.md`: 프로젝트 설명 줄, 키 이름 예시, 트래픽 규칙(복지로 100 → 참가격 하루 2,000)만 바꿨다. 나머지 규칙은 그대로다.
- `docs/STATUS.md`: 현재 단계, 할 일(T1~T5), PM 승인 대기(Q1~Q6), 열린 위험을 새 컨셉 기준으로 바꿨다.
- `docs/reference/proposal.md`: claude.ai 제안서 문서(「생필품 가격 에이전트 제안서」)의 현재 내용으로 바꿨다. 흐름 다이어그램은 글로 옮겼다.
- `docs/decisions/D1.md`와 인덱스를 추가했다.
- `experiments/context-measurement/`를 지웠다. 청년 정책 후보 API끼리 묶기 위한 측정 계획이라 새 컨셉에는 해당하지 않는다. `archive/youth-policy`에 남아 있다.

**근거**:
- D1.
- `docs/README.md`는 `reference/`를 "고치지 않는다"고 하지만, 컨셉이 바뀌어 원문 자체가 바뀌었으므로 교체했다. 이전 원문은 `archive/youth-policy`에 있고, 파일 머리에 그 사실을 적었다. PM이 계획을 승인할 때 이 교체가 포함돼 있었다.
- `.env.example`은 `.claude/settings.json`이 Claude Code의 읽기를 막고 있어 열지 못했다. 우회하지 않고 STATUS T3로 남겼다.

**확인**: 문서만 바뀌었다. 실행해 볼 코드는 없다. 바뀐 파일에 키 값이 없는지, 문서 안 상대 링크가 실제 파일을 가리키는지 확인했다(결과는 커밋 전 diff와 함께 PM에게 보고). `.env.example` 내용은 확인하지 않음.
