# 008. D3을 기록하고, 공통 정책 형식 초안을 샘플 934건에 맞춰 만들었다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: D3, T8, Q10, Q4

**계기**: PM이 Q9를 ②(LLM 질문당 최대 2회)로 승인하고 W3(공통 정책 형식 초안)을 요청했다.

**한 일**:
- D3을 기록하고 STATUS에서 Q9를 지웠다. README 서비스 흐름에 D3을 적었다.
- [schema.md](../../experiments/api-survey/schema.md)에 공통 정책 형식 초안, 출처별 매핑, 채움률을 정리했다.
- [normalize.py](../../experiments/api-survey/normalize.py)를 만들었다. `samples/`를 공통 형식으로 옮기고 필드별 채움률을 출력한다.
- 형식 확정을 Q10으로 올리고, T8을 추가했다.

**근거**:
- 코드 조건을 `null`(정보 없음), `[]`(제한 없음), 값(조건 있음) 세 가지로 나눴다. 정보가 없다고 걸러내면 받을 수 있는 정책을 놓치기 때문이다. 작업 안에서 정했고, 형식 확정(Q10) 때 PM이 함께 본다.
- 분류 공통 어휘는 온통청년 대분류 5개로 했다. D3에서 LLM이 첫 문장을 이 코드로 바꾸므로, 다른 출처도 같은 어휘로 옮겨야 한다.
- 복지로 관심주제만으로는 주거 정책이 주거로 잡히지 않는 경우가 있어(예: 청년 주택임차보증금 이자 지원), 제목 낱말로 분류를 보탰다. 낱말 목록은 임시다.

**확인**:
- `normalize.py`를 샘플에 돌렸다. 4개 출처 934건(잡알리오 200, LH 임대 73, 복지로 중앙부처 461, 지자체 200)이 모두 변환됐고, `title`·`url`이 빠진 레코드는 없었다.
- 분류 보정 뒤 위 예시가 `["복지문화", "주거"]`로 바뀐 것을 확인했다.
- 공공데이터포털 4개 출처 모두 나이가 코드로 없다(채움률 0%). 온통청년 매핑은 실제 응답이 없어 확인하지 않았다.
