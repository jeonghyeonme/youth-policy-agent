# 025. 대시보드에 AI 추천(청년 정책)과 핵심 이유를 넣었다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: PM이 객관적으로 어느 쪽이 나은지 묻고, AI 추천 이유 중 중요한 것만 대시보드에 넣어 달라고 했다.

**한 일**: [대시보드](https://claude.ai/artifact/W7N3zi26ewZkHrYMN5ZPMf) 맨 위 결론 아래에 "AI 추천: 청년 정책" 카드를 넣었다. 이유 세 가지(같은 비용에 비슷한 품질, 같은 비용으로 넓은 범위, 틀렸을 때 작은 피해), 법률 정보가 나은 경우, 청년 정책으로 갈 때 감수할 것.

**근거**: 카드 안 숫자(토큰, 쓸모 있는 근거, 범위, 피해 점수)는 대시보드의 실측·점수 데이터에서 그린다. 추천 이유는 log/021·022와 같다. 처음 기준(니즈 충족)으로 사용자 쪽 가치를 우선했다.

**확인**: 페이지 스크립트 문법 검사만 했다.
