# 019. 청년 정책 서버 필터를 LLM 없이 재서, 넓이가 순위 기능에 달렸음을 확인했다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7, Q8(청년 정책 브랜치)

**계기**: PM이 "청년 정책도 무료 LLM으로 더 나은 결과물이 나온다는 보장이 없다"고 지적했다. 청년 정책은 질문부터 답까지 시험한 적이 없었다.

**한 일**: [experiments/youth-filter-check](../../experiments/youth-filter-check/README.md). 청년 정책 브랜치 데이터 4,598건과 그 팀의 질문 10개로, 코드 필터 뒤 후보 수와 단순 키워드 순위 상위 3건을 봤다. API·LLM 호출 없음.

**근거**:
- 필터 뒤 후보 89~728건(실측). 상위 3건 중 맞는 정책 평균 약 0.8건(AI 판단).
- 청년 정책의 넓이는 순위 기능이 있어야 결과물이 된다. 법률 정보가 주제 표로 푼 근거 찾기 문제와 같은 종류다.

**확인**: 같은 스크립트를 두 번 돌려 같은 결과를 얻었다. 순위가 가장 단순한 기준선이라 청년 정책에 불리한 쪽으로 치우쳐 있다.
