# 006. 사람이 로컬에서 한 번에 샘플을 받도록 수집 스크립트를 만들었다 (2026-11-08)

> [진행 로그 인덱스](README.md) · 작성: AI(Claude Code), PM 요청 · 관련: T4, D2

**계기**: PM이 로컬 `.env`에 키를 넣었다. AI는 `.env`를 읽지도, 공공 API를 부르지도 않으므로(AGENTS.md) 사람이 실행할 스크립트가 필요했다.

**한 일**:
- `experiments/context-measurement/fetch_samples.py`: 대표 질문 A·B(D2) 조건으로 온통청년(옛·개편 주소 둘 다), 잡알리오, LH, 복지로 중앙부처·지자체를 부르고 응답을 `samples/<api>/`에 저장한다. 목록에서 ID를 뽑아 상세도 부른다.
- 네트워크 없는 부분(.env 파싱, 키 정규화, 키 지우기, ID 추출, 오류 판정, 호출 예산)을 테스트하는 `test_fetch_samples.py`. CI가 이 폴더의 `test_*.py`를 모두 돌리게 바꿨다.

**근거**:
- 트래픽: 이미 받은 샘플은 다시 부르지 않는다. 상세는 질문당 5건까지. 복지로 중앙부처는 한 번 실행에 최대 12회(한도 100). AGENTS.md "트래픽".
- 키: 공공데이터포털 인코딩·디코딩 키 중 무엇을 넣어도 한 번만 인코딩되게 맞춘다. 응답·기록에 키 원문이나 인코딩 값이 보이면 `***`로 바꾼다.
- 대표 질문 조건: A는 나이 26·서울·일자리, B는 나이 27·서울·주거·검색어 "월세". 측정용 예시 값이다.
- 추정: 온통청년 개편 주소(`/go/ythip/getPlcy`)와 파라미터, data.go.kr 오퍼레이션 경로는 문서로 확인하지 못했다. 실패하면 `fetch_log.md`에 남는 응답으로 고친다.
- 의존성 없이 Python 표준 라이브러리만 쓴다(Windows에서 `py`로 바로 실행).

**확인**:
