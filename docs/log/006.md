# 006. 공공데이터포털 샘플을 받아 응답 구조와 수집 기간을 확인했다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 실행) · 관련: T7, D1

**계기**: PM이 `collect_samples.py`를 실행해 공공데이터포털 4개 출처의 샘플(파일 48개)을 커밋했다(커밋 56603bc).

**한 일**:
- 샘플을 읽어 응답 형식, 전체 건수, 자격조건 필드의 채움과 길이를 확인했다. 결과는 [findings.md "실제 응답으로 확인한 것"](../../experiments/api-survey/findings.md)에 있다.
- STATUS의 열린 위험 두 줄(복지로 중앙부처 수집 기간, LH 자격조건)을 실측으로 고쳤다.

**근거**:
- 복지로 중앙부처 청년 대상은 152건이다. 목록의 생애주기 이름에 "청년"이 들어간 건수로 셌다. 이 기준이면 상세 수집은 2일이다(152 ÷ 100, 계산).
- 복지로 지자체 청년 비율 21%는 목록 앞 200건 기준이라 전체를 대표한다고 보지 않았다.

**확인**:
- 파일 48개 모두 HTTP 200이었다. 저장된 요청값에 키가 없었다.
- 실행 출력(잡알리오 200건, LH 300건 중 임대 73건, 복지로 중앙부처 461건 중 청년 152건, 지자체 200건 중 청년 42건)과 샘플 파일에서 다시 센 값이 같았다.
- 수집 스크립트의 JSON·XML 처리와 ID 필드 탐색이 실제 응답에서도 동작했다. 온통청년 쪽은 아직 실제 응답으로 확인하지 않았다.
