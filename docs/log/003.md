# 003. API 키 발급 절차를 정리하고, LH 상세 API를 특정했다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: T2

**계기**: PM이 키 발급부터 돕기를 요청했다. 로그인과 본인인증이 필요해 AI가 대신 신청할 수 없으므로, 따라 할 절차를 문서로 만들었다.

**한 일**:
- [api-survey/api-keys.md](../../experiments/api-survey/api-keys.md)에 온통청년과 공공데이터포털 신청 절차, 신청할 데이터셋 번호, `.env` 작성법을 정리했다.
- LH 상세 API를 15057999(분양임대공고별 상세정보 조회)로 특정했다. 공고문 첨부파일 목록(`dsAhflInfo`)과 입주자격 기타 같은 서술형이 여기에 있다. findings와 STATUS T2, 열린 위험을 고쳤다.

**근거**:
- 제안서는 "다섯 서비스 모두 개발계정은 자동승인"이라고 적었다. 그러나 온통청년 "오픈(OPEN) API 이용방법" 페이지에는 담당자 심사 후 승인한다고 되어 있다. 그래서 온통청년을 먼저 신청하도록 적었다.
- `.env`에 Decoding 키를 넣기로 한 것은 작업 안에서 정했다. 수집 스크립트가 HTTP 라이브러리의 URL 인코딩에 맡기는 쪽이 단순하기 때문이다.

**확인**:
- 온통청년 이용방법 페이지 본문, data.go.kr 검색 결과(LH API 6개), 15057999 활용가이드(2026-06-16판) docx를 읽었다.
- 실제 신청과 키 동작은 확인하지 않았다.
