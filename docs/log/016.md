# 016. 세 컨셉을 예상 결과물 기준 7개로 점수화했다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: 청년 정책 대 법률 정보 비교(log/015)에서 표와 추천이 어긋나 보인다는 PM 지적이 있었다. PM이 진행도를 빼고 예상 결과물만으로, 기준을 먼저 정해 객관적으로 비교하자고 했다.

**한 일**: 기준 7개와 가중치(사용자 쪽 70%, 만드는 쪽 30%)를 PM과 먼저 정한 뒤 [reference/concept-scorecard.md](../reference/concept-scorecard.md)를 썼다. 기존 대안은 웹에서 확인했다. youth-vs-legal.md에 대체 표시를 넣고 STATUS Q7을 고쳤다.

**근거**:
- 합계: 청년 3.28, 법률 3.31, 생필품 2.85. 청년과 법률은 점수 하나 0.5로 뒤집히는 차이라 같다고 본다.
- 사용자 쪽 소계는 청년 2.38, 생필품 2.10, 법률 1.96. 처음 요청이 "니즈 충족"이라 청년 정책을 추천했다.
- 결과를 바꾼 확인 사실: 고용노동부 AI 노동법 상담(ai.moel.go.kr, 노무사 감수), 온통청년 AI 챗봇·공공마이데이터 자가진단, 참가격 최저가 매장·장바구니 비교가 이미 있다.
- 한계: 커버리지 질문은 설계에 참여한 AI가 썼다(PM과 정한 방식은 팀원 작성). 생필품 정확성·토큰은 시험 없는 추정.

**확인**: 점수 합계를 손으로 다시 계산했다. 48.0% 수치는 기사 원문(한국경제, 2025-01-21, 알바천국 조사)으로 확인했다. 다른 기존 대안은 보도·소개 글로만 확인했고 직접 써 보지 않았다.
