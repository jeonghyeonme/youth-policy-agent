# 001. 저장소를 만들고 추적 구조를 잡았다 (2026-10-18)

> [진행 로그 인덱스](README.md)

**계기**: 기획 제안서(「청년 정책 안내 에이전트 제안서」)를 팀 저장소로 옮겨, 팀원이 어떤 AI 도구를 쓰든 같은 규칙과 같은 상황판을 보게 하려고.

**한 일**:
- 제안서 원문을 `docs/reference/proposal.md`로 옮겼다. 서비스 흐름 다이어그램은 내보내기에서 빠져 README에 글로 정리했다.
- 상황 추적 구조: `STATUS.md`(지금), `decisions/`(PM이 승인한 결정), `log/`(한 일). 제안서의 "미정 사항"은 STATUS "PM 승인 대기" Q1~Q6으로 옮겼다.
- PM 승인이 필요한 결정의 범위를 `AGENTS.md`에 정했다. 해당하면 STATUS에 올리고 승인 전에는 진행하지 않는다. 회의록 폴더는 만들었다가 PM 판단으로 뺐다.
- AI 도구 가드레일: `AGENTS.md`(Codex·Cursor·Copilot이 읽음), `CLAUDE.md`(AGENTS.md를 불러옴), `.gemini/settings.json`(Gemini CLI가 AGENTS.md를 읽게), `.claude/settings.json`(Claude Code의 `.env` 읽기 차단).
- `.env.example`, `.gitignore`, 이슈·PR 템플릿.

**근거**: 제안서 "개인정보 처리", "제약과 일정"(AI 작업 가드레일) 절.

**확인**: 문서만 바뀌었다. 실행해 볼 코드는 없다. `.claude/settings.json`의 차단은 Claude Code에서만 동작하고, 다른 도구에서는 `AGENTS.md`가 지시문으로만 쓰인다 — 실제로 막아 주지 않는다.
