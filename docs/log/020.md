# 020. 청년 정책을 질문부터 답까지 재는 스크립트를 만들었다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: 청년 정책 필터 점검(log/019) 뒤 PM이 청년 정책도 실측하자고 했다.

**한 일**: [experiments/youth-e2e](../../experiments/youth-e2e/README.md). 1회차(조건 + 검색 낱말) → 서버(필터, BM25, 중복 합치기, 상위 8건) → 2회차(최대 3개 고르고 설명). 청년 정책 데이터 4,598건을 `policies.json.gz`로 옮겼다.

**근거**:
- 법률 v5 fallback과 같은 모델·호출 수로 맞췄다. 2회차에 후보 고르기를 합쳐 D3(질문당 2회)를 지켰다.
- 작업 안에서 정한 것: 검색 낱말 확장(1회차), BM25 순위, 이름 기준 중복 합치기, 생애주기에 청년이 없는 복지 서비스 제외, 후보 8건. 임베딩(청년 정책 Q8)은 새 외부 서비스라 쓰지 않았다.
- 질문은 청년 정책 팀이 전에 쓴 10개라, 법률 정보 쪽(설계자가 쓴 질문)보다 치우침이 작다.

**확인**: `--offline`과 `--fake`로 흐름을 확인했다. 생애주기 규칙은 효과가 작았다(복지로 상당수가 생애주기 정보 없음). 실제 Groq로는 돌리지 않았다.
