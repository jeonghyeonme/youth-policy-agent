# 007. LH는 링크·마감일만 쓰기로 하고, 무료 LLM 제약에 맞춘 호출 방향을 올렸다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 실시간 검토) · 관련: D2, Q1, Q5, Q9

**계기**: PM이 LH 공고는 링크와 마감일만 보여 주기로 정했다. 또 LLM도 무료 API 키로만 구현하므로 LLM 호출을 최소로 하는 방향을 요청했다.

**한 일**:
- D2를 기록했다. LH는 공고명·지역·링크·마감일만 쓰고, 상세 API와 첨부 공고문은 쓰지 않는다.
- STATUS Q1에 LH가 D2로 정해졌다고 적고, LH 위험 항목을 지웠다.
- Q9(무료 LLM 한도 안에서 LLM을 어디에 쓰나)를 추천안과 함께 올렸다.

**근거**:
- D2의 근거는 임대 상세 샘플 5건 중 4건의 공고내용이 비어 있었다는 실측이다.
- Q9 추천안(질문당 LLM 최대 2회)의 근거는 계산이다. 조건을 버튼으로 받으면 그 턴에는 LLM이 필요 없다. 남는 일은 처음 자유 문장을 조건 코드로 바꾸는 것과 걸러진 결과를 설명하는 것뿐이다. 무료 등급의 실제 한도는 업체마다 달라 Q5에서 확인한다.

**확인**: 문서만 바뀌었다.
