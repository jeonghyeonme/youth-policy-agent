# 004. 키가 서비스마다 동작하는지 확인하는 스크립트를 만들었다 (2026-10-29)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: T2

**계기**: PM이 온통청년(청년정책 API)과 공공데이터포털 키 발급을 마쳤다. AI는 실제 호출을 하지 않으므로(AGENTS.md "API 키"), 사람이 한 번 돌릴 확인 스크립트가 필요했다.

**한 일**:
- `experiments/api-survey/check_keys.py`를 만들었다. 온통청년, 잡알리오, LH 목록과 상세, 복지로 중앙부처, 복지로 지자체를 한 번씩, 모두 6번 호출한다.
- 키는 환경변수나 루트 `.env`에서 읽고, 키와 요청 URL은 출력하지 않는다. 응답은 저장하지 않는다.
- `api-keys.md`에 실행 방법을 적고, STATUS T2를 "검토 중"으로 바꿨다.

**근거**:
- 실험 스크립트는 Python 표준 라이브러리로만 쓴다. 설치할 것이 없어 누구나 바로 돌릴 수 있기 때문이다. 서비스 기술 스택(Q6)을 정하는 것은 아니다.
- 온통청년 응답의 건수 필드 이름과 복지로 응답 형식(JSON·XML)은 실제로 받아 본 적이 없다. 그래서 건수 필드 후보를 여럿 두고, JSON과 XML을 모두 읽게 했다. 실패하면 응답 앞부분을 출력한다.

**확인**:
- 가짜 응답으로 스크립트를 돌렸다. 정상 응답 6개는 6/6 통과했다. 인증 오류(`SERVICE_KEY_IS_NOT_REGISTERED_ERROR`)와 HTML 오류 페이지는 `[FAIL]`로 나왔고, LH 목록이 실패하면 상세는 `[SKIP]`으로 나왔다. 출력에 키 문자열이 없는 것도 확인했다.
- 임시 `.env`로 읽기 기능을 확인했다. 따옴표와 `+`, `/`, `=`가 든 값을 그대로 읽었다.
- 실제 키로는 돌리지 않았다. PM 실행 결과를 기다린다.
