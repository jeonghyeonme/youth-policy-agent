# 017. 팀 논의용으로 3안 점수표를 시각화한 대시보드를 만들었다 (2026-11-01)

> [진행 로그 인덱스](README.md) · 작성: Claude Code (PM 요청) · 관련: Q7

**계기**: PM이 점수표(log/016)를 팀원들과 의논할 수 있게 시각화해 달라고 했다.

**한 일**: claude.ai 대시보드 https://claude.ai/artifact/W7N3zi26ewZkHrYMN5ZPMf 를 만들었다. 합계 타일, 사용자·만드는 쪽 막대, 기준별 점수 점 그래프, 가중치 민감도 선, 법률 정보 측정 경과 막대, 질문 커버리지 목록, 기존 서비스 표, 점수 근거 표, 의논할 것.

**근거**:
- 데이터는 [concept-scorecard.md](../reference/concept-scorecard.md)의 점수, `experiments/legal-tokens`와 청년 정책 브랜치의 토큰 실측, 웹으로 확인한 기존 서비스를 JSON 파일 4개로 옮겼다. 합계·민감도·하루 질문 수·커버리지 비율은 페이지가 그 파일로 계산한다.
- 민감도 계산(사용자 쪽 비중을 0~100%로 바꿈)에서 청년 정책과 법률 정보가 같아지는 비중은 약 71.4%로 나왔다(계산). 정한 비중 70%와 거의 겹친다. 그래서 페이지의 결론을 "팀이 정할 것은 그 비중"으로 잡았다.

**확인**: 대시보드 자체 검사는 5번 읽는 동안 "checking"에서 끝나지 않아 결과를 확인하지 못했다. 브라우저로 렌더링해 보지 않았다.
