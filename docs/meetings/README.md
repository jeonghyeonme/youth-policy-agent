# 회의록 — 인덱스

> 회의 하나에 파일 하나(`YYYY-MM-DD.md`, 같은 날 두 번이면 `YYYY-MM-DD-2.md`). 아래 틀을 복사해 쓴다.
> 회의에서 정한 것은 회의록에만 두지 않는다 — 결정은 `decisions/D<번호>.md`로, 맡은 일은 [STATUS](../STATUS.md) "할 일"로 옮겨야 끝난다.

| 날짜 | 주제 | 결정 | 새 할 일 |
| --- | --- | --- | --- |

## 틀

```markdown
# 회의 YYYY-MM-DD — <주제>

> [회의록 인덱스](README.md) · 참석: 이름, 이름 · 기록: 이름

## 안건
1. …

## 논의
- …

## 결정
- … → D<번호> (또는 "다음 회의로")

## 할 일
| 할 일 | 담당 | 기한 |
| --- | --- | --- |

## STATUS 반영
- [ ] 결정을 decisions/로 옮김
- [ ] 할 일을 STATUS에 추가
- [ ] 위 인덱스 표에 한 줄 추가
```
