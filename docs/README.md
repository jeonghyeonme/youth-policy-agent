# docs — 문서 지도

문서는 **"무슨 질문에 답하나"** 기준으로 나눈다. 사람과 AI 코딩 도구가 같은 지도를 쓴다.

원칙 세 가지:
1. **질문 하나에 답하는 자리는 하나.** 같은 내용을 여러 문서에 복사하지 않고 ID로 가리킨다.
2. **위치가 아니라 ID로 인용한다.** `D3`, `log/007`, `Q2`처럼.
3. **매번 읽히는 문서는 작게 둔다.** `STATUS.md`는 80줄을 넘기지 않는다.

## 폴더

## 작업 한 번의 흐름

1. **시작**: [STATUS.md](STATUS.md)에서 내 일과 막힌 것을 본다. 이어지는 일이면 STATUS가 가리키는 `log/`·`D` 번호를 연다.
2. **작업**: 근거(`D` 번호)를 밝히고 진행한다. [PM 승인이 필요한 결정](../AGENTS.md#pm-승인이-필요한-결정)을 만나면 **그 부분은 멈추고** STATUS "PM 승인 대기"에 Q 번호로 올린다. 그 결정에 걸리지 않는 일은 계속해도 된다.
3. **마무리**: [마무리 절차](process/wrap-up.md) — `log/NNN.md` 한 건, STATUS 내 줄 갱신, 결정이 있었으면 `D` 번호.
