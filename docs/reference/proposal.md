# 청년 정책 안내 에이전트 제안서

Oct 18, 2026 · @박정현

## 개요

사회 초년생이 채팅으로 물으면 LLM이 질문을 해석해 공공 API를 호출하고, 받을 수 있는 청년 정책 정보를 돌려주는 웹 서비스입니다. 중심 데이터는 온통청년 청년정책 API입니다.

- 목표: FDE·IT 기업 지원용 포트폴리오이자 새 기술(LLM 에이전트) 학습
- 대상 사용자: 사회 초년생
- 형태: 회원 정보를 저장하지 않는 웹 채팅 서비스

## 배경

온통청년에는 청년 정책이 3,981건 등록돼 있고(2026-10-18 기준), 기존 서비스는 대부분 조건 필터로 정책을 추립니다.

- **기존 앱의 방식**: [청정어스](https://apps.apple.com/kr/app/id6747910073) 같은 앱은 나이, 소득, 지역, 학력, 직업을 고르면 맞는 정책을 보여 줍니다. 자연어 검색은 없고 AI는 요약에만 씁니다(앱스토어 설명 기준).
- **웹 서비스에서의 문제**: 앱처럼 사용자 정보를 저장해 두는 방식은 웹 서비스에서 문제가 될 수 있습니다. 그래서 저장 없이 대화로 조건을 받는 방식을 택했습니다.
- **필터로 다루지 못하는 조건**: 온통청년 응답의 추가신청자격조건, 참여제한대상, 소득기타내용은 자유 서술형 텍스트입니다.

이 중 무엇을 차별점으로 삼을지는 아직 정하지 않았습니다(핵심 변수 미정).

## 서비스 흐름

> 원본 문서의 서비스 흐름 다이어그램(6단계, 판단 1번)은 Markdown 내보내기에서 빠졌습니다. 요약은 [README](../../README.md#서비스-흐름)를 보세요.

필요한 조건이 모일 때까지 선택지로 묻고, 조건이 다 모이면 서버가 API를 호출해 결과를 걸러 LLM이 설명합니다. 온통청년 API는 나이·소득을 요청값으로 받지 않아서, 필터링은 서버에서 합니다.

## 개인정보 처리

서버는 사용자 정보를 저장하지 않고, 대화는 브라우저 탭이 열려 있는 동안만 유지됩니다.

| 항목 | 원칙 |
| --- | --- |
| 대화 저장 | 브라우저 `sessionStorage`만 사용. 탭을 닫으면 사라짐. 서버 DB 저장 없음 |
| LLM 전송 | 선택지로 받은 값은 LLM에 보냄. 이 값들만으로는 신원 특정에 한계가 있음 |
| 서버 로그 | 채팅 내용과 선택값을 남기지 않음 |
| 공공 API 검색어 | 사용자 문장을 그대로 넣지 않고 LLM이 뽑은 키워드만 보냄 |
| API 키 | `.env`에 두고 `.gitignore`로 제외, 저장소 밖에서 팀에 공유 |

확인한 다섯 API의 요청 파라미터에는 이름, 주민번호, 연락처, 상세주소가 없습니다. 나이(복지로)와 시군구 정도만 보냅니다.

## 다음 단계: API별 컨텍스트 소모량 측정

위 API를 모두 확보해 하나씩 호출하고, LLM에 넘길 때 드는 컨텍스트 양을 재서 병합할 API를 추리는 워크플로우를 만듭니다. 방향만 정했고 세부 설계는 미정입니다.

컨텍스트는 세 곳에서 늘어납니다. 도구 정의(API당 수백 토큰 수준), API 응답(가장 큼), 대화 기록입니다.

측정 전에 정할 것:

- [ ] API 키 발급: 온통청년 마이페이지, 공공데이터포털 서비스별 활용신청
- [ ] 토큰을 어떤 기준으로 셈지 (같은 한국어도 LLM마다 토큰 수가 다름)
- [ ] 어떤 조건으로 호출해 잴지 (대표 질문 2\~3개)
- [ ] 측정 후 무엇을 기준으로 추릴지 (소모량 상한, 쓸모와의 균형)
- [ ] 코드를 둘 팀 저장소

## 제약과 일정

실질 개발 기간은 4\~5주이고, 주차별 계획은 아직 없습니다.

- **LLM**: 무료 API 사용. 팀원끼리 키를 공유하기 편해서. 업체는 미정
- **팀 작업**: 인원과 역할은 미정
- **트래픽**: 복지로 중앙부처 API는 개발계정 100으로, 팀 개발에 빠듯합니다
- **AI 작업 가드레일**: 키를 다루지 못하게 하는 설정을 GitHub 저장소로 공유 (구체 내용 미정)

## 미정 사항

아래 다섯 가지가 정해져야 구현 계획을 세울 수 있습니다.

- [ ] 온통청년과 함께 묶을 API (측정 결과로 결정 예정)
- [ ] 사회 초년생이 던질 질문 예시 2\~3개
- [ ] 핵심 변수: 이 설계에서 결과를 가장 크게 좌우하는 것
- [ ] 서술형 자격 조건을 누가 판단할지 (LLM 또는 사용자)
- [ ] LLM 업체와 팀 인원·역할
