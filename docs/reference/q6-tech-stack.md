## 추천: 1. Next.js(TypeScript) + Vercel

- **배포가 한 곳이다.** 4~5주에 배포·환경변수·도메인을 한 번만 다룬다. 서버와 화면 사이 CORS·주소 설정이 없다.
- **개인정보 원칙과 잘 맞는다.** 대화는 브라우저 `sessionStorage`, 키와 공공 API 호출은 API Route. 서버는 상태를 들고 있지 않는다.
- **채팅 UI가 쉽다.** 선택지 버튼, 판정 카드(가능 / 확인 필요 / 해당 안 됨 + 근거·링크), 스트리밍을 자유롭게 만든다.
- **실험 코드를 옮기는 비용은 작다.** 필터(지역·나이·취업·신청 가능), 순위(D9), 코드 판정(D10)은 합쳐 200줄 안팎의 순수 함수다. 옮기면서 TypeScript 타입으로 "나이는 숫자로 거른다"(log/017) 같은 규칙을 코드에 박을 수 있다.

**조건**: 팀원 대부분이 Python만 쓸 줄 알면 **2. FastAPI + React**가 낫다. 실험 코드를 그대로 쓰고, 서버를 Python으로 두고, 화면만 React로 만든다. 팀 인원·역할(Q5)이 정해지면 이 조건부터 확인한다.

**3. Streamlit은 빼기를 권한다.** 대화 상태를 서버 세션에 두는 구조라 "대화는 브라우저에만" 원칙과 맞지 않는다.

## 함께 정할 것

- **호스팅**: 추천안은 Vercel 무료(Hobby). 개인·비상업 용도 플랜이라 포트폴리오에는 맞다. 새 외부 서비스라 PM 승인이 필요하다. 호스팅의 요청 로그에 대화 내용·선택값이 남지 않도록, 서버 코드는 요청 본문을 로그에 찍지 않는다(AGENTS.md "개인정보").
- **최상위 디렉토리**: 코드를 어디에 둘지(예: 저장소 루트에 Next.js 프로젝트, 또는 `app/` 아래). 최상위 디렉토리 추가는 PM 승인 대상이다.
- **사용할 라이브러리 후보**(작업자가 정해도 되는 범위로 보이나 함께 적는다): Groq 공식 SDK(`groq-sdk`) 또는 OpenAI 호환 SDK, 스키마 검증 `zod`, UI는 Tailwind CSS.

## 확인하지 않은 것

- Vercel 무료 플랜의 함수 실행 시간 제한·대역폭 같은 구체 수치는 이번에 문서로 확인하지 않았다. Groq 응답은 실험에서 3~4초였다(log/019).
- 팀원의 언어 경험(Q5).
