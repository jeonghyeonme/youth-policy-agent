## 목표

질문 하나가 **처음부터 끝까지** 돈다. 화면에서 선택지로 조건을 받고 → 온통청년(+LH)을 부르고 → 정책을 고르고(D9) → 자격을 판정해(D10) → 근거와 함께 답한다. 배포된 링크로 대표 질문 A·B(D2)를 시연한다.

**만들지 않는 것(이번 5주)**: 로그인, 대화 저장(서버), 복지로·잡알리오(D6), 여러 키 돌려 쓰기(D8).

## 구조 (D11·D12)

```
web/                          Next.js(TypeScript), Vercel Root Directory = web
├── app/                      화면: 채팅, 선택지 버튼, 판정 카드
│   └── api/chat/route.ts     서버: 대화 한 턴 처리 (키는 여기서만)
├── lib/
│   ├── policy/               순수 함수 — 테스트의 중심
│   │   ├── filter.ts         지역·나이·취업·신청 가능 (나이는 숫자로, log/017)
│   │   ├── rank.ts           D9 순위, 상위 8건
│   │   └── codeVerdict.ts    D10 서버 코드 판정
│   ├── sources/              공공 API 클라이언트 + 메모리 캐시(D8)
│   │   ├── youthcenter.ts
│   │   └── lh.ts
│   └── llm/                  Groq 호출, 도구 정의, 프롬프트, 토큰 예산
└── test/fixtures/            experiments/의 저장된 샘플 일부 (테스트는 API를 부르지 않는다)
```
