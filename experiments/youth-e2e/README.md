# 청년 정책 질문→답 실측

법률 정보안은 질문부터 답까지 쟀지만 청년 정책안은 LLM 두 호출을 따로만 시험했다. 같은 조건(Groq gpt-oss-120b, 질문당 LLM 2회)으로 처음부터 끝까지 잰다. 비교 대상은 [legal-tokens](../legal-tokens/README.md)의 v5 fallback이다.

## 흐름

| 단계 | 하는 일 |
| --- | --- |
| 1회차 LLM | 자유 문장 → 분야·나이·지역·취업상태·학력 + 검색 낱말 (JSON). 청년 정책 브랜치 시험 v2 프롬프트에 검색 낱말만 더했다 |
| 서버 | 마감 제외, 코드 조건으로 거르기, 생애주기에 청년이 없는 복지 서비스 제외 → BM25 순위 → 같은 이름 정책 합치기 → 상위 8건 |
| 2회차 LLM | 후보 8건 중 질문에 맞는 정책을 최대 3개 고르고 설명 (JSON). 맞는 게 없으면 이유를 쓴다 |

- 데이터: [policies.json.gz](policies.json.gz). 청년 정책 브랜치(`claude/exciting-goldberg-y71yhi`, 839b5ff) 수집 샘플을 `normalize.py`로 변환한 4,598건(마감 제외 2,144건). 공개 정책 데이터라 커밋했다.
- 질문: 청년 정책 팀이 LLM 시험에 쓴 10개와 정답 조건. 이 질문도 법률 정보 쪽과 마찬가지로 AI가 준비했다.
- 공공 API는 부르지 않는다. Groq만 부른다(질문당 2회, 10개면 약 20회).

## 실행

```bash
python3 experiments/youth-e2e/pipeline.py --offline
```

LLM 없이 정답 조건과 질문 낱말로 서버 단계만 본다.

```bash
python3 experiments/youth-e2e/pipeline.py --fake
```

키 없이 흐름만 확인한다.

```bash
python3 experiments/youth-e2e/pipeline.py --max-wait 1800
```

실제로 돌린다. 결과는 `results/y1/<모델>/`에 쌓인다. 요약만 다시 보려면 `--report`.

## 볼 것

- 질문당 토큰과 하루 질문 수 (법률 v5 fallback: 질문당 약 3,100, 하루 약 64개).
- 고른 정책이 질문에 맞는지. 사람이 제목과 설명을 보고 판단한다 (법률 v5: 조문 선택 12건 중 11건).
- 설명이 없는 정보를 가정하는지 (청년 v1: 9건 중 3건).

## 오프라인 기준선 (2026-11-01, LLM 없이)

정답 조건과 질문 낱말만 쓴 서버 단계의 상위 3건이다. 1회차의 검색 낱말 확장과 2회차의 고르기가 빠진 하한이다.

- 잘 된 질문: 서울 월세(청년 월세 지원), 대전 전세 보증금(임차보증금 이자지원, 전월세 대출보증), 위원회 참여(청년정책조정위원회 등).
- 안 된 질문: 부산 목돈(점심 지원·공연), 경기 고졸 직업훈련(산재근로자 훈련 등), 인천 건강·상담(장애인·의료급여 검진), 제주 이직·교육(농민수당 등).
- 데이터 문제 두 가지: 복지로 출처 상당수가 생애주기 정보가 없어 노인·장애인 대상 서비스가 섞인다. 온통청년에는 "위원회 설치", "시스템 시범 설치"처럼 개인이 신청할 수 없는 정책 사업도 섞여 있다.

- 토큰(실측): 답을 낸 8건 평균 3,540, 하루 약 56개. 법률 v5 fallback(약 3,100, 약 64개)과 비슷하다.
- 형식 오류(실측): 10건 중 2건이 2회차 JSON 검증 실패(빈 출력). 법률 정보 120b는 0/15였다. 서비스에서는 재시도가 필요하다.
- 정책 선택(판단): 고른 21건 중 약 17건이 질문에 쓸모 있다. 답을 낸 8건 모두 쓸모 있는 정책을 1개 이상 냈다. 질문 10개는 분야 5개에 걸쳐 있다.
- 설명 오류(판단): 자격을 틀리게 추론한 것 2건(q03 첫 번째, q04 두 번째). 데이터에 자격조건이 비어 있을 때 "제한이 없다"로 읽는 표현이 여러 건. 정보 없음과 제한 없음을 구분하라는 규칙으로 줄일 수 있다(추정).
- 오프라인 기준선(서버만)에서 나빴던 부산 목돈, 경기 직업훈련, 제주 교육이 1회차 검색 낱말과 2회차 고르기로 맞는 정책을 찾았다.
