# 대표 질문 (D2로 A·B 확정)

> [측정 계획](README.md) · **A·B로 확정됐다 ([D2](../../docs/decisions/D2.md), 2026-11-07).** 아래는 결정 전에 올린 후보와 추천안이다.

대표 질문은 측정(T4) 때 API를 어떤 조건으로 부를지 정한다. 그래서 질문끼리 **다른 API, 다른 조건 종류**를 건드리게 골랐다. 근거 코드는 [API 조사](api-survey.md).

| # | 질문 (사용자가 칠 법한 문장) | 대화로 모을 조건 | 건드리는 API·필드 | 이 질문으로 재는 것 |
| --- | --- | --- | --- | --- |
| A | "서울 사는 26살인데 아직 취업 못 했어요. 받을 수 있는 지원금 있어요?" | 나이, 지역(서울), 취업상태(미취업) | 온통청년 일자리(`jobCd` 미취업자), 잡알리오(근무지역), 복지로(나이) | 코드 조건만으로 얼마나 걸러지나. 나이 하나로 걸러진 뒤 남는 응답 크기 |
| B | "첫 직장 때문에 자취를 시작해요. 연봉 3천인데 월세 지원 받을 수 있나요?" | 나이, 지역, 연소득, 무주택 여부 | 온통청년 주거(`earnCndSeCd`, 소득 서술형), LH(임대주택·주거복지 공고), 복지로 지자체(`slctCritCn`) | 서술형 소득·자격 조건이 얼마나 많고 긴가 (Q4 크기) |
| C | "중소기업 다니는 신입인데 목돈 모으는 정책 뭐 있어요?" | 나이, 재직 여부, 회사 규모 | 온통청년(`sbizCd` 중소기업, 키워드 금리혜택·대출) | 키워드 검색만으로 충분한가. 한 API로 끝나는 질문의 기준값 |
| D | "부산에서 창업 준비 중인 27살이에요. 지원 사업 알려줘요" | 나이, 지역(부산), 창업 단계 | 온통청년(`jobCd` (예비)창업자), 복지로 지자체(시군구 이름) | 서울 아닌 지역에서 지자체 정책이 얼마나 붙나 |

## 추천: A, B (필요하면 C 추가)

- **A와 B가 대분류 중 일자리·주거를 나눠 맡고, 후보 API 다섯 개를 모두 한 번 이상 건드린다.** 측정 대상이 빠지지 않는다.
- **A는 코드 필터, B는 서술형 조건**을 대표한다. 두 값의 차이가 서버 필터링과 LLM 판단 중 무엇에 기댈지(Q3·Q4)의 근거가 된다.
- C는 API 하나로 끝나서 기준값으로 쓸 만하다. 호출 여유(복지로 중앙부처 100)가 빠듯하면 뺀다.
- D는 A와 조건 종류가 겹친다. 지역 차이를 보려면 A의 지역만 바꿔 다시 재면 된다.

나이·연봉 같은 값은 측정용 예시다. 실제 사용자 값이 아니다.
