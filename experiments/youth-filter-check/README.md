# 청년 정책 서버 필터 점검 (2026-11-01)

청년 정책안은 LLM 부분만 시험했고, "수천 건 중 질문에 맞는 정책 고르기"는 시험하지 않았다. 법률 정보안과 같은 기준으로 비교하려고 LLM 없이 이 부분만 쟀다. 실행법은 [check.py](check.py) 머리말.

## 방법

- 데이터: 청년 정책 브랜치의 수집 샘플을 `normalize.py`로 변환한 4,598건(마감 제외 2,144건).
- 질문: 청년 정책 팀이 LLM 시험에 쓴 질문 10개와 정답 조건. LLM 해석은 완벽하다고 가정했다(시험 v1 50칸 중 50 정답).
- 필터: 분야, 지역(전국 포함), 나이, 마감 여부. 학력·취업상태는 정책 쪽 코드가 비어 있는 경우가 많아 쓰지 않았다.
- 순위: 질문 낱말이 제목·요약·지원내용에 나온 횟수. 아주 단순한 기준선이다.

- 필터 뒤에도 질문당 89~728건이 남는다(실측). LLM 2회차는 몇 건만 설명하므로 순위가 서비스 품질을 정한다.
- 단순 키워드 순위로는 상위 3건 중 맞는 정책이 평균 약 0.8건이다(사람 판단, 질문 10개). 같은 정책이 출처·연도별로 겹쳐 나온다.
- 즉 청년 정책안의 넓이는 순위 기능이 받쳐 줘야 생긴다. 법률 정보안이 주제 표로 푼 "근거 찾기"와 같은 종류의 문제이고, 청년 정책안에서는 아직 풀지 않았다(Q8 임베딩, 중복 제거 미정).
- 한계: 순위는 가장 단순한 기준선이다. 더 나은 순위(BM25, 임베딩, LLM 재정렬)로는 결과가 달라진다. 맞는지 판단은 AI가 했다.
